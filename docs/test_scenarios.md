## Известные проблемы

### STT коверкает фамилию Хайретдинов
Whisper может распознать как "Харединов", "Рядинов", "Райер Единов". Substring match в `DoctorsService.find_by_name()` не найдёт совпадение. Варианты обхода при тесте:
- Говори "Олег Замильевич" (отчество распознаётся лучше)
- Говори "к детскому психиатру" → пойдёт по ветке fallback, но не appointment
- Говори "хочу пройти ЭПИ" → найдёт по процедуре, потом "запишите к нему"

### Длинные ответы = долгое TTS
Если бот генерирует длинный LLM-ответ (описание врача), TTS может занять 3-4 секунды. Это нормально для текущей архитектуры.
