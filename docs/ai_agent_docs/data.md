# Данные

Файлы: `data/doctors.json`, `data/faq.json`

---

## doctors.json

База врачей клиники. Текущее содержимое - **1 запись**:

```json
[
  {
    "name": "Хайретдинов Олег Замильевич",
    "visiting_hours": "10:00 - 16:00",
    "experience": "более 30 лет",
    "procedures": ["ЭПИ"],
    "diseases": [
      "невротическое расстройство",
      "тревожное расстройство",
      "расстройство пищевого поведения",
      "нарушение развития"
    ],
    "info": "Врач-психиатр детский, к.м.н, врач высшей категории по специальности «Психиатрия». Имеет статус \"Московский врач\".",
    "cost": "Первичный приём 5000 рублей, повторный 3500 рублей"
  }
]
```

### Формат записи

| Поле | Тип | Описание |
|------|-----|----------|
| `name` | string | Полное ФИО врача |
| `visiting_hours` | string | Часы приема (свободный формат) |
| `experience` | string | Стаж (свободный формат) |
| `procedures` | string[] | Список процедур (используется для поиска) |
| `diseases` | string[] | Список заболеваний (используется для поиска) |
| `info` | string | Описание квалификации (отдается LLM для краткого пересказа) |
| `cost` | string | Стоимость приёма (опционально, по умолчанию "") |

### Использование

- `DoctorsService.find_by_name()` - поиск по `name`
- `DoctorsService.find_by_procedure()` - поиск по `procedures`
- `DoctorsService.find_by_disease()` - поиск по `diseases`
- `appointment_node` - для предложения слотов найденному врачу
- `doctor_info_node` - для ответов на вопросы о враче

## faq.json

FAQ клиники. Текущее содержимое - **3 записи**:

```json
[
  {
    "question": "Где находится клиника?",
    "answer": "Клиника находится в Москве, точный адрес можно уточнить у администратора."
  },
  {
    "question": "Как отменить запись?",
    "answer": "Чтобы отменить запись, свяжитесь с клиникой по телефону или напишите в чат."
  },
  {
    "question": "Какие способы оплаты доступны?",
    "answer": "Доступна оплата картой и наличными."
  }
]
```

### Формат записи

| Поле | Тип | Описание |
|------|-----|----------|
| `question` | string | Вопрос (используется для keyword matching) |
| `answer` | string | Ответ (передается LLM для переформулировки) |

### Использование

- `FAQService.match()` - keyword matching по токенам `question`
- `faq_node` - формирует `FAQ_ANSWER_PROMPT` из matched `question` + `answer`
- LLM переформулирует `answer` в естественный ответ

## Mock-данные в MedeskService

Кроме JSON-файлов, `medesk_service.py` содержит захардкоженные слоты расписания:

| Врач | Слоты |
|------|-------|
| Хайретдинов Олег Замильевич | 2026-04-06 10:00, 2026-04-06 11:00, 2026-04-07 14:00 |
| Иванова Анна Сергеевна | 2026-04-08 12:00, 2026-04-08 15:00, 2026-04-10 09:30 |

Иванова Анна Сергеевна присутствует **только в mock-слотах**, но **не в doctors.json** - ее нельзя найти через `DoctorsService`, только напрямую через `MedeskService`.
