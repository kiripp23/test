# Сценарии диалогов — Psy Family Bot

Полный каталог всех возможных сценариев голосового бота клиники Psy Family.

---

## Глобальное правило: призыв к действию (CTA)

**Каждое сообщение бота без исключений заканчивается призывом к действию.** Бот — оператор клиники, и каждый ответ ведёт к следующему шагу.

| Текущий контекст | CTA |
|-----------------|-----|
| Нет pending_action | «Записать вас на приём?» / «Хотите записаться?» |
| `confirm_slot` | «Вам подходит время шестого апреля в одиннадцать утра?» |
| `ask_patient_name` | «Как вас зовут?» |
| `ask_birth_date` | «Подскажите, пожалуйста, дату рождения.» |
| `confirm_alt_doctor` | «Записать вас на приём?» |

**Примеры:**
- ❌ «У Хайретдинова стаж более 30 лет.» — нет CTA
- ✅ «У Хайретдинова стаж более 30 лет. Подскажите, пожалуйста, дату рождения.» — с CTA
- ❌ «К сожалению, я не располагаю такой информацией.» — нет CTA
- ✅ «К сожалению, я не располагаю такой информацией. Уточните у администратора. Как вас зовут?» — с CTA

## 1. Основной сценарий записи (happy path)

Полный цикл: выбор врача → слот → имя → дата рождения → подтверждение.

```
Бот: Здравствуйте! Клиника Psy Family, чем могу помочь?
Пациент: Хочу записаться к Хайретдинову
Бот: У Хайретдинова Олега Замильевича есть окно шестого апреля в десять утра. Записать вас?
Пациент: Да
Бот: Отлично, записываю вас на шестого апреля в десять утра. Как вас зовут?
Пациент: Иван Петров
Бот: Подскажите, пожалуйста, дату рождения.
Пациент: 15 мая 1985
Бот: Вы записаны на шестого апреля в десять утра к врачу Хайретдинову Олегу Замильевичу, уведомление придёт вам по номеру. Ждём вас на приёме! Могу ещё чем-то помочь?
Пациент: Нет, спасибо, до свидания
Бот: До свидания, будьте здоровы! Ждём вас на приёме.
[signal: end_call]
```

**Ключевые моменты:**
- `end_call` отправляется только по явному прощанию, не после записи
- При запросе имени бот напоминает выбранный слот
- После записи бот предлагает помочь ещё

## 2. Запись с указанием даты/времени

Пациент сразу говорит желаемую дату.

### 2a. Совпадение найдено

```
Пациент: Запишите к Хайретдинову на шестое апреля в десять
Бот: Да, у Хайретдинова Олега Замильевича свободно шестого апреля в десять утра, делаем запись?
```

### 2b. Совпадение не найдено, есть альтернатива

```
Пациент: Запишите к Хайретдинову на пятое апреля
Бот: К сожалению, у Хайретдинова Олега Замильевича на 5 апреля уже занято, предлагаем вам запись на шестого апреля в десять утра. Вам будет удобно?
```

### 2c. Совпадение не найдено, альтернатив нет

Переход к сценарию [предложения другого врача](#4-предложение-другого-врача).

## 3. Отклонение слота и альтернативы

Пациент отказывается от предложенного слота — бот предлагает следующий.

```
Бот: У Хайретдинова Олега Замильевича свободно шестого апреля в десять утра, делаем запись?
Пациент: Нет, не подходит
Бот: Тогда можем предложить шестого апреля в одиннадцать утра у Хайретдинова Олега Замильевича. Вам будет удобно?
Пациент: Тоже нет
Бот: Тогда можем предложить седьмого апреля в четырнадцать часов у Хайретдинова Олега Замильевича. Вам будет удобно?
```

**Ключевые моменты:**
- Отклонённые слоты сохраняются в `rejected_slots` и не предлагаются повторно
- Шаблоны предложений слотов варьируются (4 варианта)
- Если все слоты исчерпаны → предложение другого врача

## 4. Предложение другого врача

Когда у выбранного врача нет свободных слотов.

```
Бот: К сожалению, у Хайретдинова Олега Замильевича сейчас нет свободных слотов. Могу предложить вам запись к Лазебному Даниилу Леонидовичу. [информация о враче]
Пациент: Хорошо
Бот: У Лазебного Даниила Леонидовича свободно восьмого апреля в двенадцать часов, делаем запись?
```

### 4a. Пациент просит конкретного другого врача

```
Пациент: Нет, мне нужен Некрылов
Бот: Понимаю. По данным CRM-системы, у Некрылова Юрия Ивановича доступны следующие слоты: ...
```

### 4b. Все врачи исчерпаны

```
Бот: К сожалению, сейчас нет свободных специалистов по данному направлению. Оставьте, пожалуйста, ваш номер телефона — мы перезвоним, как только появится запись.
```

**Ключевые моменты:**
- Система отслеживает `tried_doctors`, чтобы не предлагать одного врача дважды
- Альтернативный врач подбирается по совпадению специализации/заболеваний

## 5. Поиск врача по заболеванию

Пациент не знает к кому записаться, описывает проблему.

### 5a. Врач найден

```
Пациент: У меня невротическое расстройство, хочу записаться
Бот: Хайретдинов Олег Замильевич занимается лечением невротических расстройств. Хайретдинов Олег Замильевич — детский врач-психиатр, кандидат медицинских наук... Записать вас на приём?
Пациент: Да
Бот: У Хайретдинова Олега Замильевича есть окно шестого апреля в десять утра. Записать вас?
```

### 5b. Уточнение у текущего врача

```
Пациент: Занимается ли Хайретдинов лечением депрессии?
Бот: Да, Хайретдинов Олег Замильевич занимается лечением депрессии. [информация о враче]
```

### 5c. Заболевание не в профиле клиники

```
Пациент: У меня болит спина
Бот: Наша клиника специализируется на психическом здоровье. По вашему вопросу рекомендуем обратиться в профильную клинику. Если вас интересует помощь психиатра или психотерапевта — будем рады помочь!
```

### 5d. Заболевание не в профиле конкретного врача

```
Пациент: Лечит ли Хайретдинов кардиологию?
Бот: К сожалению, в карточке Хайретдинова Олега Замильевича нет информации по этому направлению. Уточните, пожалуйста, у администратора.
```

## 7. Вопросы о враче

### 7a. Стаж

```
Пациент: Какой стаж у Хайретдинова?
Бот: У Хайретдинова Олега Замильевича стаж более 30 лет.
```

### 7b. Часы приёма

```
Пациент: Когда принимает Хайретдинов?
Бот: Часы приёма Хайретдинова Олега Замильевича: 10:00 - 16:00.
```

### 7c. Специализация / общая информация

```
Пациент: Расскажите подробнее про Хайретдинова
Бот: Хайретдинов Олег Замильевич — детский врач-психиатр, кандидат медицинских наук, врач высшей категории. Имеет статус «Московский врач». Записать вас на приём?
```

### 7d. Стоимость приёма

```
Пациент: Сколько стоит приём у Хайретдинова?
Бот: К сожалению, я не располагаю такой информацией. Уточните, пожалуйста, у администратора.
```

### 7e. Врач не найден

```
Пациент: Расскажите про Сидорова
Бот: Не удалось найти врача. Уточните, пожалуйста, ФИО.
```

**Ключевые моменты:**
- Стаж и часы приёма — шаблонные ответы (быстрые)
- Общая информация и специализация — через LLM (естественный язык)
- Ответ всегда без префикса «Информация о враче:»

## 9. Вопросы во время сбора данных

Пациент задаёт вопрос вместо того, чтобы назвать имя или дату рождения.

### 9a. Вопрос вместо имени

```
Бот: Отлично, записываю вас на шестого апреля в десять утра. Как вас зовут?
Пациент: А расскажите про его стаж
Бот: У Хайретдинова Олега Замильевича стаж более 30 лет.
Пациент: Иван Петров
Бот: Подскажите, пожалуйста, дату рождения.
```

### 9b. «А как тебя зовут?» — не принимается за имя

```
Бот: Как вас зовут?
Пациент: А как тебя зовут?
Бот: Я не могу предоставить вам данную информацию. Так как же вас зовут?
```

### 9c. Вопрос вместо даты рождения

```
Бот: Подскажите, пожалуйста, дату рождения.
Пациент: А зачем это?
Бот: [LLM объясняет зачем нужна дата рождения] Подскажите, пожалуйста, вашу дату рождения.
```

### 9d. Вопрос о клинике во время сбора данных

```
Бот: Подскажите, пожалуйста, дату рождения.
Пациент: А где находится клиника?
Бот: Клиника находится по адресу: Москва, ул. Шверника, 17к3.
Пациент: 15 мая 1985
Бот: Вы записаны на ...
```

**Ключевые моменты:**
- Бот отвечает на вопрос и мягко переспрашивает данные
- `pending_action` сохраняется — бот помнит что ждёт имя/дату
- Если LLM не извлёк имя/дату — сообщение не принимается как данные

## 10. Переключение контекста

Пациент переключается между темами, контекст врача сохраняется.

### 10a. Вопрос о клинике после обсуждения врача

```
Пациент: Расскажите про Хайретдинова
Бот: Хайретдинов Олег Замильевич — детский врач-психиатр...
Пациент: А как называется ваша клиника?
Бот: Наша клиника называется Psy Family — экспертный центр психиатрической медицины в Москве.
Пациент: Хочу записаться
Бот: У Хайретдинова Олега Замильевича есть окно шестого апреля в десять утра. Записать вас?
```

### 10b. Вопрос о враче во время подтверждения слота

```
Бот: У Хайретдинова Олега Замильевича свободно шестого апреля в одиннадцать утра, делаем запись?
Пациент: А он хороший доктор?
Бот: Хайретдинов Олег Замильевич — детский врач-психиатр, кандидат медицинских наук... Записать вас на приём?
Пациент: Да
Бот: Отлично, записываю вас на шестого апреля в одиннадцать утра. Как вас зовут?
```

**Ключевые моменты:**
- `pending_doctor_name` сохраняется через FAQ/fallback переходы
- `pending_action` и `selected_slot` сохраняются через вопросы о враче
- Возврат к записи использует текущий контекст, не начинает заново

## 11. Согласие после отвлечения

Пациент отвлёкся на вопрос, затем соглашается. Бот возвращается к текущему слоту.

```
Бот: Шестого апреля в одиннадцать утра у Хайретдинова Олега Замильевича. Вам будет удобно?
Пациент: А он хороший доктор?
Бот: [информация о враче] Записать вас на приём?
Пациент: Ну давайте
Бот: Отлично, записываю вас на шестого апреля в одиннадцать утра. Как вас зовут?
```

**Ключевые моменты:**
- Бот НЕ предлагает третий слот — возвращается к текущему второму
- `make_appoint` и `doctor_ok` без новых дат при `confirm_slot` → трактуются как `chosen_slot`
- Если пациент явно просит другую дату — тогда ищем новый слот

## 12. Завершение диалога

Диалог завершается ТОЛЬКО по явному прощанию пациента.

```
Пациент: До свидания
Бот: До свидания, будьте здоровы! Ждём вас на приёме.
[signal: end_call]
```

```
Пациент: Пока!
Бот: До свидания, будьте здоровы! Ждём вас на приёме.
[signal: end_call]
```

**Ключевые моменты:**
- После записи `end_call` НЕ отправляется — пациент может захотеть ещё что-то спросить
- `end_call` только при интенте `end_conversation`
- Прощальное сообщение тёплое: «Ждём вас на приёме»

```
Пациент: Нужен живой человек
Бот: Переключаю вас на оператора, оставайтесь на линии.
[signal: transfer_operator]
```

## 14. Произвольные сообщения (fallback)

Сообщения, не попавшие ни в один сценарий, обрабатываются LLM с контекстом диалога.

### 14a. Общий вопрос

```
Пациент: Спасибо за помощь
Бот: Пожалуйста! Если понадобится помощь — обращайтесь. Хотите записаться на приём?
```

### 14b. Личный вопрос боту

```
Пациент: Как тебя зовут?
Бот: Я не могу предоставить вам данную информацию. Могу помочь с записью к врачу.
```

### 14c. Не связанная с клиникой тема

```
Пациент: Какая сегодня погода?
Бот: К сожалению, я не могу обсуждать темы, не связанные с клиникой. Хотите записаться к врачу?
```

### 14d. Произвольное сообщение после обсуждения врача

```
[после обсуждения врача]
Пациент: Понятно, спасибо
Бот: Хотите записаться на приём к Хайретдинову Олегу Замильевичу?
```

**Ключевые моменты:**
- Бот никогда не говорит, что он ИИ/бот/нейросеть
- Всегда пытается подвести к записи на приём
- Использует 6 последних сообщений из истории для контекста

## 15. Ошибочные и граничные случаи

### 15a. Врач не найден

```
Пациент: Запишите к Сидорову
Бот: Не удалось найти врача Сидоров. Подскажите, пожалуйста, ФИО врача точнее.
```

### 15b. Запись без указания врача

```
Пациент: Хочу записаться
Бот: Подскажите, пожалуйста, что вас беспокоит? Так я смогу подобрать подходящего специалиста.
```

### 15c. Запись без указания врача (в контексте врача)

```
[после обсуждения Хайретдинова]
Пациент: Хочу записаться
Бот: У Хайретдинова Олега Замильевича есть окно шестого апреля в десять утра. Записать вас?
```

### 15d. Нечёткий матчинг фамилии

```
Пациент: Запишите к Харединову    [опечатка]
Бот: У Хайретдинова Олега Замильевича ...  [fuzzy match, порог 0.75]
```

### 15e. Фамилия совпадает с отчеством врача

```
Пациент: Давайте к Иванову
Бот: Не удалось найти врача Иванов. Подскажите, пожалуйста, ФИО врача точнее.

**Ожидание:** «Иванов» НЕ должен матчить «Некрылов Юрий Иванович» — совпадение с отчеством не считается. Аналогично «Петров» не матчит «Петрович».

### 15f. Фамилия в косвенном падеже

```
Пациент: Расскажите про Хайретдинова    [родительный падеж]
→ извлекается как "Хайретдинов"          [именительный]
```

## 16. Полная карта состояний

### Состояния (`pending_action`)

| Состояние | Описание | Вход | Выход |
|-----------|----------|------|-------|
| `None` | Начальное состояние / завершено | Старт или завершение записи | Любой интент |
| `confirm_slot` | Ожидание подтверждения слота | Предложение слота | `chosen_slot` → `ask_patient_name` |
| `ask_patient_name` | Ожидание имени пациента | Подтверждение слота | Имя извлечено → `ask_birth_date` |
| `ask_birth_date` | Ожидание даты рождения | Имя получено | Дата извлечена → `None` (запись завершена) |
| `confirm_alt_doctor` | Ожидание ответа по альтернативному врачу | Слоты исчерпаны | Согласие → `confirm_slot` у нового врача |

### Сигналы (`call_signal`)

| Сигнал | Когда отправляется | Действие |
|--------|-------------------|----------|
| `None` | По умолчанию | Диалог продолжается |
| `end_call` | Пациент попрощался (`end_conversation`) | Бот кладёт трубку |
| `transfer_operator` | Пациент просит оператора (`wants_operator`) | Перевод на живого оператора |

### Маршрутизация (`final_route`)

| Маршрут | Когда | Ноды |
|---------|-------|------|
| `appointment` | Запись, слоты, подтверждение | `appointment_node` |
| `doctor_info` | Вопросы о враче, поиск по заболеванию/процедуре | `doctor_info_node` |
| `faq` | Вопросы о клинике | `faq_node` |
| `fallback` | Всё остальное, прощание, оператор | `fallback_node` |

### Интенты (12 типов)

| Интент | Описание | Пример |
|--------|----------|--------|
| `make_appoint` | Хочет записаться | «Запишите к Хайретдинову» |
| `asks_about_slot` | Спрашивает о свободных датах | «Какие есть свободные даты?» |
| `chosen_slot` | Соглашается на предложенный слот | «Да», «Хорошо» |
| `slot_not_suitable` | Отклоняет слот | «Нет, не подходит» |
| `want_procedure` | Ищет врача по заболеванию/процедуре | «У меня депрессия» |
| `question_about_doctor` | Вопрос о конкретном враче | «Какой стаж?» |
| `question_about_clinic` | Вопрос о клинике | «Где находится?» |
| `doctor_ok` | Согласие на предложенного врача | «Хорошо, давайте к нему» |
| `doctor_not_ok` | Отказ от предложенного врача | «Нет, не хочу к нему» |
| `wants_operator` | Просит оператора | «Переведите на человека» |
| `end_conversation` | Прощается | «До свидания» |
| `arbitrary_message` | Всё остальное | «Спасибо», «Как дела?» |

## 17. Edge cases: резкое переключение темы

Пациент может в любой момент сменить тему. Бот должен ответить на новый вопрос и сохранить контекст записи.

### 17a. Запись → вопрос о клинике → обратно к записи

```
Пациент: Запишите к Хайретдинову
Бот: У Хайретдинова Олега Замильевича есть окно шестого апреля в десять утра. Записать вас?
Пациент: А вы работаете по выходным?
Бот: Да, клиника работает в субботу и воскресенье с 09:00 до 18:00. Запишем вас на шестое апреля?
Пациент: Да
Бот: Отлично, записываю вас на шестого апреля в десять утра. Как вас зовут?
```

**Ожидание:** бот ответил на вопрос о графике, вернулся к слоту, не потерял контекст.

### 17b. Запись к одному врачу → переключение на другого

```
Пациент: Хочу записаться к Хайретдинову
Бот: У Хайретдинова Олега Замильевича есть окно шестого апреля в десять утра. Записать вас?
Пациент: А что скажете про Некрылова?
Бот: Некрылов Юрий Иванович — врач-психиатр, специализируется на лечении ПТСР, депрессии... Записать вас на приём?
Пациент: Да, лучше к нему
Бот: У Некрылова Юрия Ивановича свободно восьмого апреля в одиннадцать утра. Записать вас?
```

**Ожидание:** бот переключился на нового врача, старый слот сброшен.

### 17c. Обсуждение врача → FAQ → обратно к записи

```
Пациент: Расскажите про Лазебного
Бот: Лазебный Даниил Леонидович — психиатр, работает и со взрослыми, и с детьми... Записать вас на приём?
Пациент: А можно онлайн?
Бот: Да, доступны три формата: очный приём, онлайн-консультация по видеосвязи и выезд врача на дом.
Пациент: Хорошо, запишите к нему очно
Бот: У Лазебного Даниила Леонидовича свободно восьмого апреля в двенадцать часов. Записать вас?
```

**Ожидание:** после FAQ бот помнит врача и предлагает его слоты.

### 17d. Сбор имени → вопрос о стоимости → обратно к имени

```
Бот: Отлично, записываю вас на шестого апреля в десять утра. Как вас зовут?
Пациент: А сколько стоит приём?
Бот: К сожалению, я не располагаю такой информацией. Уточните, пожалуйста, у администратора. Так как же вас зовут?
Пациент: Мария Иванова
Бот: Подскажите, пожалуйста, дату рождения.
```

**Ожидание:** бот ответил на вопрос, переспросил имя, данные не потерялись.

### 17e. Сбор даты рождения → вопрос об адресе → обратно

```
Бот: Подскажите, пожалуйста, дату рождения.
Пациент: Кстати, а где вы находитесь?
Бот: Клиника находится по адресу: Москва, ул. Шверника, 17к3. Подскажите, пожалуйста, вашу дату рождения.
Пациент: 3 марта 1990
Бот: Вы записаны на ... Ждём вас на приёме! Могу ещё чем-то помочь?
```

**Ожидание:** бот ответил на вопрос, переспросил дату, завершил запись.

### 17f. Подтверждение слота → перевод на оператора

```
Бот: У Хайретдинова Олега Замильевича свободно шестого апреля в десять утра, делаем запись?
Пациент: Подождите, переведите меня на оператора
Бот: Переключаю вас на оператора, оставайтесь на линии.
[signal: transfer_operator]
```

**Ожидание:** запрос оператора приоритетнее любого pending_action.

### 17g. Подтверждение слота → прощание

```
Бот: У Хайретдинова Олега Замильевича свободно шестого апреля в десять утра, делаем запись?
Пациент: Нет, я передумал, до свидания
Бот: До свидания, будьте здоровы! Ждём вас на приёме.
[signal: end_call]
```

**Ожидание:** прощание приоритетнее pending_action.

### 17h. Множественные переключения подряд

```
Пациент: Хочу записаться к Хайретдинову
Бот: У Хайретдинова Олега Замильевича есть окно шестого апреля в десять утра. Записать вас?
Пациент: Какой у него стаж?
Бот: У Хайретдинова Олега Замильевича стаж более 30 лет.
Пациент: А где клиника?
Бот: Клиника находится по адресу: Москва, ул. Шверника, 17к3.
Пациент: А можно онлайн?
Бот: Да, доступны три формата: очный приём, онлайн-консультация и выезд на дом.
Пациент: Ладно, запишите очно
Бот: Отлично, записываю вас на шестого апреля в десять утра. Как вас зовут?
```

**Ожидание:** после 3 переключений бот всё ещё помнит врача и слот.

### 17i. Заболевание → другой врач → запись к первому

```
Пациент: У меня ПТСР
Бот: Некрылов Юрий Иванович занимается лечением ПТСР... Записать вас на приём?
Пациент: А что насчёт Шипотько?
Бот: Шипотько Дмитрий Александрович — психотерапевт, специализируется на семейной терапии... Записать вас на приём?
Пациент: Нет, давайте всё-таки к Некрылову
Бот: У Некрылова Юрия Ивановича свободно восьмого апреля в одиннадцать утра. Записать вас?
```

**Ожидание:** бот переключается между врачами, запоминает последний выбор.

### 17j. Запись → жалоба → возврат

```
Пациент: Запишите к Хайретдинову
Бот: У Хайретдинова Олега Замильевича есть окно шестого апреля в десять утра. Записать вас?
Пациент: А почему так мало свободных дат?
Бот: К сожалению, расписание формируется на ограниченный период. Если предложенное время не подходит, могу посмотреть другие варианты. Вам удобно шестого апреля в десять утра?
Пациент: Ладно, давайте
Бот: Отлично, записываю вас на шестого апреля в десять утра. Как вас зовут?
```

**Ожидание:** произвольный вопрос при confirm_slot → fallback ответ → слот сохранён.

## 18. Edge cases: нестандартные ответы пациента

### 18a. Пациент называет полное ФИО + дату рождения сразу

```
Бот: Как вас зовут?
Пациент: Петров Иван Сергеевич, 15 мая 1985 года
Бот: Вы записаны на ... Ждём вас на приёме! Могу ещё чем-то помочь?
```

**Ожидание:** если LLM извлёк и имя, и дату — пропустить второй вопрос.

### 18b. Пациент отвечает односложно

```
Бот: У Хайретдинова Олега Замильевича свободно шестого апреля в десять утра, делаем запись?
Пациент: Угу
```

**Ожидание:** «Угу», «Ага», «Ну да» → трактуется как согласие (`chosen_slot`).

### 18c. Пациент отвечает неоднозначно

```
Бот: У Хайретдинова Олега Замильевича свободно шестого апреля в десять утра, делаем запись?
Пациент: Ну не знаю, а других вариантов нет?
```

**Ожидание:** `asks_about_slot` или `slot_not_suitable` → предложить альтернативу.

### 18d. Пациент отвечает не по-русски

```
Пациент: I want to make an appointment
Бот: [fallback — LLM отвечает на русском, предлагает записаться]
```

**Ожидание:** бот отвечает на русском, пытается продолжить диалог.

### 18e. Пациент говорит дату в разных форматах

```
Пациент: 15.05.1985
Пациент: пятнадцатого мая тысяча девятьсот восемьдесят пятого
Пациент: 1985 год, май, пятнадцатое число
```

**Ожидание:** LLM извлекает `birth_date` из любого формата.

### 18f. Пациент отказывается называть дату рождения

```
Бот: Подскажите, пожалуйста, дату рождения.
Пациент: Не хочу говорить
Бот: Дата рождения нужна для оформления записи в медицинской системе. Подскажите, пожалуйста, вашу дату рождения.
Пациент: Нет
Бот: Я понимаю ваши опасения. Без даты рождения, к сожалению, не получится оформить запись. Подскажите, пожалуйста, вашу дату рождения.
```

**Ожидание:** бот объясняет зачем нужна дата, мягко переспрашивает, не сдаётся.

### 18g. Пациент даёт имя по частям

```
Бот: Как вас зовут?
Пациент: Иван
Бот: Подскажите, пожалуйста, дату рождения.
```

**Ожидание:** даже неполное имя принимается — LLM извлекает то, что есть.

### 18h. Пациент здоровается повторно в середине диалога

```
[в середине диалога]
Пациент: Здравствуйте
Бот: Здравствуйте! Чем могу помочь?
```

**Ожидание:** `arbitrary_message` → fallback отвечает приветствием.

### 18i. Пациент отправляет пустое или очень короткое сообщение

```
Пациент: .
Пациент: Ок
Пациент: Ммм
```

**Ожидание:** зависит от контекста. При `confirm_slot` → скорее согласие. Без контекста → fallback.

### 18j. Пациент называет нескольких врачей

```
Пациент: Что скажете про Хайретдинова и Некрылова?
```

**Ожидание:** LLM извлекает первую фамилию, бот рассказывает о ней. Пациент может спросить о втором отдельно.

### 18k. Пациент спрашивает о записи к врачу, которого нет в системе, а потом к существующему

```
Пациент: Запишите к Сидорову
Бот: Не удалось найти врача Сидоров. Подскажите, пожалуйста, ФИО врача точнее.
Пациент: Тогда к Хайретдинову
Бот: У Хайретдинова Олега Замильевича есть окно шестого апреля в десять утра. Записать вас?
```

**Ожидание:** бот не застревает после ошибки, переключается на нового врача.

## 20. Edge cases: эмоциональные и сложные ситуации

### 20a. Пациент выражает тревогу

```
Пациент: Мне очень плохо, я не знаю к кому обратиться
Бот: Я вас понимаю. В нашей клинике работают специалисты, которые помогут вам. Подскажите, что именно вас беспокоит — тревога, нарушения сна, подавленное настроение? Так я смогу подобрать подходящего врача.
```

**Ожидание:** бот реагирует эмпатично, направляет к записи без давления.

## 21. Обработка нестандартных запросов (message_category)

Бот классифицирует каждое сообщение по двум осям:
1. **patient_intent** — что пациент хочет (12 интентов)
2. **message_category** — к какой категории относится сообщение (5 категорий)

### Категории сообщений

| Категория | Описание | Маршрут | LLM? |
|-----------|----------|---------|------|
| `clinic_related` | Вопросы о клинике, врачах, здоровье | → FAQ (с контекстом) | Да, если нет FAQ-совпадения |
| `off_topic` | Не связано с клиникой (погода, спорт) | → Fallback (шаблон) | Нет |
| `emotional` | Сильные эмоции, паника, страх | → Fallback (эмпатия) | Да |
| `greeting` | Приветствие | → Fallback (шаблон) | Нет |
| `gratitude` | Благодарность | → Fallback (шаблон) | Нет |

### 21a. Off-topic — мягкий отказ

```
Пациент: Какой счёт в матче?
Бот: Я могу помочь вам с записью к врачу и информацией о клинике. Хотите записаться на приём или узнать о наших специалистах?
```

### 21b. Emotional — эмпатичный ответ

```
Пациент: Мне очень плохо, я не знаю что делать...
Бот: Я понимаю, что вам сейчас тяжело. Наши специалисты помогут разобраться с ситуацией. Хотите, я подберу вам врача?
```

### 21c. Greeting — быстрый шаблон

```
Пациент: Привет!
Бот: Здравствуйте! Клиника Psy Family, меня зовут Алиса. Чем могу помочь?
```

### 21d. Gratitude — быстрый шаблон

```
Пациент: Спасибо большое!
Бот: Пожалуйста! Могу ещё чем-то помочь?
```

### 21e. Clinic-related arbitrary → FAQ с контекстом

Если пациент задаёт вопрос о клинике, но ни один конкретный интент не подходит, сообщение направляется в FAQ-ноду. Если стем-матчинг не находит совпадение, LLM получает полный список FAQ как контекст.

```
Пациент: Как к вам доехать?
Бот: Клиника находится по адресу: Москва, ул. Шверника, 17к3. Хотите записаться на приём?
```

### 21f. Off-topic → затем запись

```
Пациент: Как попасть на Марс?
Бот: Я могу помочь вам с записью к врачу и информацией о клинике. Хотите записаться на приём?
Пациент: Хочу записаться к Хайретдинову
Бот: У Хайретдинова Олега Замильевича свободно... [нормальный flow]
```

## 22. Непрофильные процедуры и поиск врача по заболеванию

### 22a (Кейс 30). Процедура не нашей специализации

Пациент спрашивает о процедуре, которой нет в клинике (стоматология, офтальмология и т.п.). Бот объясняет специализацию и предлагает то, чем может помочь.

```
Пациент: Здравствуйте, а зубы можно у вас лечить?
Бот: Наша клиника специализируется на психическом здоровье. По вашему вопросу рекомендуем обратиться в профильную клинику. Если вас интересует помощь психиатра или психотерапевта — хотите записаться?
Пациент: Ну зубы там лечить
Бот: Наша клиника специализируется на психическом здоровье. По вашему вопросу рекомендуем обратиться в профильную клинику. Если вас интересует помощь психиатра или психотерапевта — хотите записаться?
```

**Было (ошибка):** «Пока не удалось подобрать врача. Уточните, пожалуйста, процедуру или заболевание.» — бессмысленно, т.к. пациент уже назвал процедуру.

**Стало:** бот объясняет специализацию клиники и предлагает свои услуги.

### 22b (Кейс 31). Запись без врача → заболевание → подбор специалиста

Пациент хочет записаться, но не знает к какому врачу. Бот спрашивает, что беспокоит. Пациент называет заболевание — бот находит врача по заболеванию и предлагает слот.

```

Пациент: Тревожные расстройства
Бот: У Хайретдинова Олега Замильевича свободно шестого апреля в десять утра, делаем запись?
```

**Было (ошибка):** «Подскажите, пожалуйста, к какому врачу вы хотите записаться?» — бот игнорировал заболевание и просил имя врача.

**Стало:** `appointment_node` при отсутствии имени врача ищет специалиста через `find_by_disease()` и `find_by_procedure()`.

### 22d. Процедура не найдена и заболевание не указано

```
Пациент: Мне нужен врач
Бот: Подскажите, что вас беспокоит? Так я смогу подобрать подходящего специалиста.

## 23. Врач не найден — эскалация ответа (кейс 33)

Бот не зацикливается в "уточните ФИО". Стратегия зависит от полноты имени:

| Запрос | Ответ |
|--------|-------|
| Только фамилия ("Иванов") | «Не удалось найти врача по имени Иванов. Подскажите, пожалуйста, полное ФИО.» |
| Полное ФИО ("Иванов Сергей Иванович") | «К сожалению, в нашей клинике нет врача с таким именем. Хотите записаться к другому специалисту?» |

### 23a. Фамилия → полное ФИО → определённый отказ

```
Пациент: Иванов у вас работает?
Бот: Не удалось найти врача по имени Иванов. Подскажите, пожалуйста, полное ФИО.
Пациент: Иванов Сергей Иванович
Бот: К сожалению, в нашей клинике нет врача с таким именем. Хотите записаться к другому специалисту?
```

### 23b. Полное ФИО сразу → определённый отказ

```
Пациент: Запишите к Иванову Сергею Ивановичу
Бот: К сожалению, в нашей клинике нет врача с таким именем. Хотите записаться к другому специалисту?
```

**Было (ошибка):** бот бесконечно повторял «Не удалось найти врача. Уточните ФИО» даже после полного ФИО.

**Стало:** если имя содержит 2+ слова — определённый отказ с предложением альтернативы.

## 24. Отказ от предложенного врача (кейс 34)

Когда пациент говорит «нет, мне нужен другой врач» — бот ищет альтернативного специалиста с таким же профилем через `find_similar_doctor()`, а не отправляет в fallback (который может галлюцинировать).

### 24a. Отказ → альтернатива

```
Пациент: Тревожное расстройство
Бот: Хайретдинов Олег Замильевич занимается лечением тревожного расстройства. [...] Записать вас на приём?
Пациент: Нет, мне нужен другой врач
Бот: [альтернативный врач с описанием] Записать вас на приём?
```

### 24b. Все альтернативы исчерпаны

```
Пациент: Нет, другого
Бот: К сожалению, других специалистов по данному направлению сейчас нет. Хотите записаться к другому врачу или уточнить у администратора?
```

**Было (ошибка):** `doctor_not_ok` не обрабатывался роутером → fallback → LLM выдумывал несуществующих врачей ("Садыкова Дина Равильевна").

**Стало:** `doctor_not_ok` → `doctor_info` → `find_similar_doctor()` → реальная альтернатива из базы.

### 25a. Неполное ФИО — просим полное

```
Бот: Отлично, записываю вас на шестого апреля в десять утра. Как вас зовут?
Пациент: Иванов
Бот: Для записи мне нужны имя и фамилия. Подскажите, пожалуйста, ваше полное ФИО.
Пациент: Иванов Иван
Бот: Подскажите, пожалуйста, дату рождения.
```

**Было (ошибка):** «Иванов» (1 слово) принималось как ФИО, бот переходил к дате рождения.

**Стало:** минимум 2 слова (имя + фамилия). Одно слово → «Подскажите полное ФИО».

### 25b. Вопрос во время сбора имени — без дублирования

```
Бот: Как вас зовут?
Пациент: А как тебя зовут?
Бот: Меня зовут Алиса. Как вас зовут?
```

**Было (ошибка):** «Как я могу к вам обращаться? Так как же вас зовут?» — два вопроса об одном.

**Стало:** CTA встроен в контекст системного промпта LLM, `_append_after_llm` убран. LLM заканчивает ответ одним вопросом.

### 25c. Graceful error при сбое LLM

```
Пациент: Привет
Бот: Извините, произошла техническая ошибка. Попробуйте повторить вопрос или начните новый диалог командой /chat.
```

**Было (ошибка):** HTTP 500 → «Ошибка API: 500».

**Стало:** `extract_node` и `app.py` ловят исключения, возвращают человеческое сообщение.

### 33a. Согласие + «расскажите подробнее»

```
Бот: Шестого апреля в десять утра у Хайретдинова Олега Замильевича свободно. Вам подходит?

- «Мне забронировать для вас окошко?»
- «Желаете закрепить за собой дату и время?»

## 35. Поиск врача по заболеванию: «кто лечит X?» (кейс 46)

Пациент спрашивает «кто у вас лечит невротическое расстройство?» — бот должен найти врача и предложить запись.

### 35a. «Кто лечит невротическое расстройство?»

```
Пациент: А кто у вас лечит невротическое расстройство?
Бот: Хайретдинов Олег Замильевич занимается лечением невротического расстройства. Детский врач-психиатр, к.м.н... Записать вас на приём?

| Имя/дата приоритетнее интента (кейс 38) | Если `patient_name` или `birth_date` извлечены → appointment, даже если LLM ошибся с интентом |
